Security Policy

Supported Versions

The following versions of idontScanner are currently supported with security updates:

Version	Supported
Latest release	:white_check_mark:v4.0.0
Older releases	:x:v3.6.2

Reporting a Vulnerability

If you believe you have found a security vulnerability in idontScanner, please report it privately.

Security issues can be reported through:

* GitHub: https://github.com/durwinam/idontScanner
* Telegram: https://t.me/idontProjectGP

Please do not disclose security vulnerabilities through public GitHub issues.

When reporting a vulnerability, please provide as much information as possible, including:

* A description of the issue
* Steps to reproduce
* Affected version
* Potential impact
* Any relevant logs or proof of concept

We will review all security reports and investigate confirmed issues. Security fixes will be released when necessary.

Responsible Disclosure

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing vulnerability details.

Thank you for helping keep idontScanner secure.
