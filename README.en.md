### Professional SNI / TLS Detection and Diagnostics Panel for VPS

**idontScanner** is a lightweight, fast, and Self-Hosted panel for checking TLS connection status, DNS/TCP/TLS timing, certificates, ALPN, Cipher, domain status, and scan history.

> 🎯 Project goal: Providing a clean and reliable tool for **Network / TLS Diagnostics on Targets you are authorized to inspect**.
>
> This project is not designed for broad Internet scanning, generating settings to bypass network restrictions, or creating operational configurations for bypassing filtering.

---

## 🚀 Quick Installation

The fastest installation method on GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/durwinam/idontScanner/main/install.sh | sudo bash
```

The installer automatically:

- Installs Python and the required dependencies.
- Creates a dedicated Virtual Environment.
- Creates the `idontscanner` system user.
- Prepares the SQLite database.
- Asks you for the admin Username and Password.
- Suggests port `8088` and, if it is occupied, selects the next available port.
- Enables the systemd service.
- Performs a Health Check.
- If UFW is enabled, configures the Rule for the panel port.

### Installation from ZIP File

```bash
unzip idontScanner-v3.0.4.zip
cd idontScanner-3.0.4
sudo bash install.sh --fresh
```

> `--fresh` removes the previous installation, database, and previous settings. Do not use this option for a normal Update.

## 🔄 Update Without Reinstallation

After installation, you no longer need to run the Installer again for every version.

### Recommended Method

```bash
sudo idontScanner update
```

### Direct Method

```bash
sudo bash /opt/idontScanner/update.sh
```

Update:

- Downloads the new source from GitHub.
- Preserves `.env`.
- Preserves the SQLite Database.
- Preserves Username / Password.
- Preserves History.
- Preserves Domains.
- Preserves Telegram settings.
- Preserves the Scheduler.
- Updates Dependencies.
- Runs the database Migration.
- Restarts the service.
- Performs a Health Check.

## 🔍 Scanners

### ⚡ VPS Speed Test

Dedicated VPS network test for bounded Download, Upload, Latency and Jitter measurements.

### 🎯 Custom Ping Target

Domain scans can optionally use a user-supplied IP as the TCP/TLS connection target while preserving the scanned hostname as SNI.

### 🌐 Domain Scanner

TLS scanning of active domains and displaying:

- Status
- Latency
- DNS Time
- TCP Time
- TLS Handshake
- TLS Version
- ALPN
- Cipher
- IP
- Certificate
- Issuer
- Expiration
- SAN

The standard TLS port in the Scanner is **443**, and it is internally kept separate from the Host; therefore, SNI always remains a pure hostname.

### 🎯 SNI / TLS Check

Checking TLS behavior for a specific Target and SNI, without changing the standard HTTPS connection logic.

### ☁️ CDN Diagnostics

Checking a specific Endpoint and displaying connection information and Provider Hint for CDN diagnostics.

### ⚡ Connection Tester
Connection Tester automatically detects configurations generated by Xray-compatible panels and supports the following formats for Endpoint detection:

- VLESS
- VMess
- Trojan
- Shadowsocks
- Hysteria2
- WireGuard `.conf`

For configurations with TCP/TLS, the following information is checked at the Endpoint level:

- Host / Port
- Protocol / Transport
- Security / SNI
- DNS / TCP / TLS timing
- TLS Version
- ALPN
- Cipher
- Destination IP

For UDP/QUIC protocols such as Hysteria2, Shadowsocks, and WireGuard, the program does not report a TCP connection as protocol success and only displays the related Endpoint/DNS information.

Direct access tests to Instagram / YouTube / Telegram are also performed from the VPS itself and do not use the entered configuration to route service traffic.

> UUID, password, auth, and private key are not displayed in the output, and the configuration is not retained for permanent storage.

## 📡 Service Diagnostics

The following services are tested to diagnose Reachability from the VPS itself:

- Instagram
- YouTube
- Telegram

Each service is checked with multiple Attempts and the following metrics are reported:

- DNS
- TCP
- TLS
- HTTP Response
- Min
- Max
- Average
- Jitter
- HTTP Status

These numbers represent **Latency from the VPS → Service Endpoint** and should not be interpreted as the actual overall service speed.

## 🤖 Telegram Bot

Telegram is optional and works with **Polling**; therefore, to use the Bot, you do not need to place the panel behind HTTPS or a Webhook.

Settings can be configured from:

**Settings → Telegram Bot**

Available settings:

- Bot Token
- Owner Telegram ID
- Multiple Admin Telegram IDs

Only the registered Owner and Admins are allowed to use the Bot.

## 🔐 Security

- Passwords are not stored as Plaintext.
- Password Hashes are generated with Salt and `scrypt`.
- Sessions are signed with a separate Secret.
- Mutation APIs have CSRF protection.
- The service runs with the dedicated `idontscanner` User.
- Systemd runs with `NoNewPrivileges` and file restrictions.
- Domain input is validated as a hostname.
- SQLite data is stored outside the Application Source.
- Update does not delete local information.
